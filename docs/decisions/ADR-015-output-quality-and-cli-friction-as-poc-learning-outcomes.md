# ADR-015: Output quality and CLI friction as PoC learning outcomes

- **Type:** Architecture
- **Status:** Accepted
- **Date:** 2026-04-20
- **Superseded by:** —
- **Related:** —

## Context

Setting acceptance thresholds for output quality before having real usage data is guessing.

## Decision

Treat output quality and CLI friction thresholds as PoC learning outcomes.

## Consequences

Architecture must enable fast test loops and traceable artifacts instead of requiring invented acceptance thresholds upfront.
