# Additional Output Destinations

Status: deferred product idea

## What

Support output destinations beyond local markdown files, such as OpenClaw memory, kDrive, or other user-selected stores.

## Where It Comes From

- The discovery report listed possible destinations after correction and summarization: structured markdown to disk, OpenClaw memory, kDrive push, or combinations.
- The current PoC architecture keeps final markdown exports as the baseline.
- The local-first architecture requires any future destination to respect sovereignty and explicit user control.

## Current Boundary

PoC implementation should write local user-owned outputs.
Do not add external destination integrations unless this idea is explicitly promoted.
