# AGENTS.md

Folder-level guidance for `docs/ideas/`.

## Purpose

This folder stores deferred product and architecture ideas.
Ideas are provenance records, not requirements, not research results, and not implementation tasks.

## Default Handling

- Do not read this folder for normal coding tasks unless the user request or issue explicitly references a specific idea.
- Do not expand current implementation scope based on ideas in this folder.
- Do not promote an idea into architecture, requirements, research, or implementation work without an explicit user decision.
- Keep every idea as its own markdown file.
- Each idea file should explain both what the idea is and where it came from.
